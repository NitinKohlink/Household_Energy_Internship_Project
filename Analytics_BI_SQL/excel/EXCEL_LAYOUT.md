# Excel Workbook Layout

The final workbook contains:

1. `KPI_Summary` - recruiter-friendly snapshot
2. `Daily_Energy` - cleaned daily data
3. `Hourly_Energy` - forecasting-ready data
4. `Model_Results` - MAE/RMSE/R2 comparison
5. `Clusters` - normalized cluster profiles

Recommended Excel features: tables, filters, simple conditional formatting, KPI cells and a few charts.
